# 🥁 Virtual Drum Kit

A fun, interactive web application that allows you to play virtual drums right from your browser! Whether you want to click the drum pads or use your keyboard to trigger sounds, this project brings music-making to your fingertips.

## Features
* **Dual Input Support:** Play drums by clicking the virtual pads or pressing specific keys on your keyboard.
* **High-Quality Audio:** Each drum corresponds to a unique and realistic sound.
* **Visual Feedback:** Buttons light up with an animated effect when pressed or clicked.
* **Responsive Design:** Fully responsive layout that works great on desktop, tablet, and mobile devices.

##  Technologies Used
* **HTML5:** Structure and layout of the drum pads.
* **CSS3:** Styling, and responsive design.
* **JavaScript:** DOM manipulation, event listeners, and audio playback.

##  How to Play
1. Open the project in your web browser.
2. Click on the visual drum pads with your mouse.
3. Alternatively, use the designated keyboard keys (e.g., W, A, S, D, J, K, L) to play hands-free!
